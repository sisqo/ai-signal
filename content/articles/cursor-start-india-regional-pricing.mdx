Cursor now sells a plan that exists in one country only. It is called [Cursor Start](https://cursor.com/blog/cursor-start-india). It costs ₹649 a month, tax included, which is about $7. Cursor Pro costs $20 a month everywhere else. Start went on sale on July 28, and you can only buy it in India.

Cursor is a code editor built around AI agents. You describe a job and the agent writes the code, runs it, and fixes what breaks.

The price is the news here. Most software companies pick one dollar price and convert it into local money. Cursor picked a smaller number for one market. That is a different decision, and it will not stay limited to India.

## What ₹649 buys

Start sits between Cursor's free plan and Pro. It gives you two models. One is Grok 4.5, xAI's coding model, which topped an agentic benchmark [when it launched in July](/articles/grok-4-5-coding-cost-benchmarks). The other is Composer, Cursor's own cheaper model.

You get more agent requests than the free plan. An agent request is one job you hand to the agent. The plan works on the desktop app, the web, the command line, and the iOS app.

The strongest part is cloud agents. These run on Cursor's machines instead of yours. They write code, run tests, and open pull requests while you do other work. A pull request is a proposed change that a person reviews before it joins the project. Always-on cloud agents were a higher-tier feature until now.

One thing is missing from the announcement. Cursor does not publish the request limits. The blog post says "generous access" and leaves it there. So you cannot compare Start and Pro on paper. You have to run your own work through it and watch where the limit stops you.

## What Pro still has

| | Start (India only) | Pro (everywhere) |
|---|---|---|
| Price | ₹649/month, tax included | $20/month |
| Included models | Grok 4.5, Composer | Every major model |
| Models from other AI labs | No | Yes |
| Bugbot, Auto mode, Automations | No | Yes |
| Cursor SDK | No | Yes |
| Cloud agents | Yes | Yes |
| Paying for extra usage | No | Yes, on demand |

The last row matters most. On Pro you can buy more capacity when you run out. On Start you stop until the month resets. Cursor is direct about it: "Cursor Start covers everyday building. When you need more, it's easy to change your plan to Pro."

The other missing pieces are smaller. Bugbot reviews your pull requests for bugs. Auto mode picks a model for you. Automations run jobs on a schedule. The Cursor SDK is a toolkit for building your own tools on top of Cursor. Most people who code every day never open any of them.

You can also pay in rupees through UPI, India's instant payment system, or with a credit or debit card. That sounds small. It is not. Card-only billing blocks a lot of people who have no international card.

## Why India, and why now

India is Cursor's third-largest market. Its user base there grew more than three times in one year, to over three million developers. Cursor also says developers in India send more agent requests per person than developers anywhere else.

Put those three facts together. The market is large, growing fast, and full of heavy users. And the global price is $20 a month. That number reads differently against Indian salaries than it does in San Francisco. Start reads like an answer to exactly that gap. It is also a bet. Cursor is trading revenue per user for more users, in the one market where its users work hardest.

## Everyone else converts and stops

Look at what the competition charges in the same country. Listings for India put GitHub Copilot Pro near ₹997 a month. That figure includes GST, India's 18% sales tax, which foreign software companies must add. Claude Pro lists near ₹2,000. Neither number is a discount. Both are the dollar price in rupees.

Cursor Start undercuts both, and it does it on purpose. That is the part worth watching. [GitHub made Copilot free to install last month](/articles/github-copilot-free-desktop-app-cost-controls) and still charges the same dollar rate to use it. Meta did the opposite this month and [cut its price by 125 times in exchange for your code](/articles/meta-muse-code-contributor-tier). Cursor found a third answer: charge less, ask for nothing extra, and limit it by country.

If this works, it will not stop at one market. Brazil, Indonesia, Nigeria, and Vietnam all have the same shape. Many developers, fast growth, and salaries that make $20 a month a real decision. Expect country plans to spread.

## What to do about it

**If you are in India and use Cursor free, switch.** Always-on cloud agents for ₹649 is a large gain for a small price. The free plan does not come close.

**If you are in India and pay for Pro, check what you actually use.** Open your usage page. Check whether you ever pick a model from another lab. Check whether you use Bugbot or the SDK. If the answer is no, Start saves you about two thirds of the bill.

**If you often run out of capacity, stay on Pro.** Start has no way to buy more. A month with a hard deadline in it is the wrong month to find that out.

**If you are outside India, you cannot buy this.** Cursor sells Start in India only and bills it in rupees. Watch which country gets the next one instead.

The wider lesson is simple. One global price was never a rule. It was a habit. A company with three million users in one country just broke it.
